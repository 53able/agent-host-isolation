# Strict-memory dispatch gate

The automatic path is deliberately narrow: a trusted host controller receives a `strict-memory` `InspectBlocked` event, validates a new Apple Container `guest-build` manifest and attempt, rechecks the source snapshot bytes, runs live resource probes, and only then executes the target `task.command`. The guest gets no network or credential broker. Artifacts pass through a private staging directory and the result gate after the guest and its resources have stopped and been removed.

`scripts/guest_build_runner.py` provides the bounded command path. It uses compiler-generated create/start/stop operations, a host wall-time and output watchdog, ownership-checked cleanup, and a read-only output-volume exporter. Its current supported profile caps wall time at 30 seconds, logs at 1 MiB, and imported artifacts at 32 MiB. A failed command, failed exporter, failed cleanup, or rejected artifact cannot produce a successful import.

`scripts/verify_strict_memory_dispatch.py` exercises the exact runner on the local Apple Container host. It probes a normal `task.command` and result-gate import, wall and log watchdogs, declared disk and process limits, symlink artifact rejection, and cleanup. It combines this with a fresh memory-OOM probe. `scripts/strict_memory_dispatch.py` runs those checks again before each attempted automatic dispatch, compares the target image and resource profile with the tested profile, and refuses incomplete or failed checks. It claims the target attempt durably and serializes automatic runs through one VM slot. Imported files are placed under `/var/tmp/agent-host-isolation/imports/<task-id>/<attempt-id>`.

On the recorded Apple Container 1.2.2 host, the automatic gate is **blocked**: a root guest with `nproc=32` spawned 40 processes, and a guest wrote 40 MiB to a volume requested at 16 MiB. The volume reports a 16 MiB configuration but presents approximately 132 MiB to the guest. These observations do not satisfy the declared process and disk enforcement contracts. Resolve both limits and rerun the exact-host probes before enabling automatic execution. The manual escalation request remains available.

The runner handles `task.command` as the full path selected for this profile. It is not a general agent orchestrator, network gateway, credential broker, or proof of isolation for another image, host, runtime version, or resource profile.
